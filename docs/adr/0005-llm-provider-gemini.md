# 5. LLM provider: Gemini Flash-Lite 무료 티어로 시작, 인터페이스 뒤에 두어 교체 가능하게

- 상태: Accepted
- 날짜: 2026-10-09

## 배경

AI 무드 제안(`POST /api/ai/mood-suggest`, `docs/spec.md` §3)에 LLM이 필요하다. 이 호출은 `/record`에서 메모를 쓰는 동안 디바운스로 반복 발생하고, 실패해도 기록 저장 흐름을 막지 않는다(실패 시 조용히 스킵). 즉 **품질이 조금 낮아도 되고 호출 단가가 낮아야 하는** 분류 작업이다. 아직 실사용자가 없는 개발·검증 단계라 비용을 0으로 두고 싶다.

후보는 다음과 같았다.

- **Claude Haiku 4.5** (`claude-haiku-4-5`): 입력 $1 / 출력 $5 (100만 토큰당). 지속적인 무료 티어는 없고, 신규 계정에 일회성 크레딧이 있다는 정보가 있으나 공식 확인은 못 했다. 호출 1건 약 $0.0005로 추정(입력 약 300토큰 + 출력 약 50토큰 가정)되어 비용 부담은 작다.
- **Google Gemini Flash-Lite**: 무료 티어가 있고 카드 등록이 필요 없다.
- **Groq (Llama 3.3 70B)**: 무료 티어(분당 30회, 일 1,000회 수준, 2차 출처)가 있다.
- **OpenRouter `:free` 모델**: 무료 한도가 일 50회(누적 결제 $10 이상이면 1,000회)로 작고 모델 라인업이 자주 바뀐다.

## 결정

**Gemini 3.5 Flash-Lite(`gemini-3.5-flash-lite`) 무료 티어를 쓰고, 호출은 `MoodSuggester` 인터페이스(`shared/lib/ai/`) 뒤에 둔다.**

- Gemini 2.5 Flash-Lite는 공식 문서상 신규 프로젝트의 접근이 제한되고 3.5 세대가 권장되므로 3.5를 쓴다.
- SDK 없이 `fetch`로 `generateContent`를 직접 호출한다. 엔드포인트가 하나뿐이라 의존성을 늘릴 이유가 없고, iTunes provider 구현과 일관된다.
- provider 교체 지점은 `shared/lib/ai/index.ts`의 한 줄이다. Claude Haiku 구현체를 추가해 같은 입력으로 품질·비용을 비교할 수 있다.
- 허용 mood 목록은 호출 측(route)이 주입한다. `shared`가 `entities`를 import하지 않게 해 의존 방향을 지킨다.
- 구조화 출력(JSON 스키마 + enum)을 요청하되, **서버에서 응답을 다시 검증**한다. enum 밖 값, 빈 reason, 파싱 실패는 모두 실패로 처리해 조용히 스킵한다. 메모는 `<memo>` 태그로 감싸 데이터로만 다루게 하고, 사용자 입력 안의 같은 태그는 제거한다(프롬프트 인젝션 완화).
- 엔드포인트는 로그인 사용자만 호출할 수 있고(`proxy.ts`는 `/api`를 보호하지 않아 route에서 직접 검사), 메모는 5자 이상 200자 이하, 호출 타임아웃은 5초다.

## 결과

**긍정적**

- 개발·검증 단계 비용이 0원이다.
- 인터페이스 덕분에 Claude Haiku 등으로 교체 비용이 낮다(구현체 1개 + 배선 1줄). 같은 입력으로 provider를 비교하는 실험을 할 수 있다.
- LLM 실패가 핵심 흐름(기록 저장)을 막지 않는다.

**부정적 / 트레이드오프**

- **무료 티어는 입력 데이터가 제품 개선에 사용될 수 있다**(공식 가격 페이지 확인). 현재는 테스트 데이터뿐이지만, 실사용자의 메모가 들어오기 전에 유료 티어나 다른 provider로 옮기거나 사용자 고지를 해야 한다.
- 무료 티어의 한도는 공식 문서에 수치가 없고 AI Studio에서만 확인된다. 2026-10-09 AI Studio Rate limit 페이지 기준 `gemini-3.5-flash-lite`는 분당 15회(RPM), 분당 입력 250K 토큰(TPM), 일 500회(RPD)였다(사용 이력이 없는 상태에서 확인한 값이라 변동 가능). 한도를 넘으면 추천이 조용히 사라진다(기록은 정상 동작). 디바운스(800ms)와 쿼리 캐시로 호출 수를 줄이지만, 하루 500회가 개인 프로젝트 데모에는 충분한 대신 공개 트래픽에는 부족할 수 있다.
- 모델 세대가 빠르게 바뀐다(2.5 접근 제한이 그 예). 모델명은 `gemini.ts`의 상수 하나로 둔다.

## 재검토 조건

- 실사용자가 생기거나 공개 데모 트래픽이 늘 때(데이터 사용 정책, 한도)
- 제안 품질이 낮아 사용자가 AI 추천을 자주 바꿀 때(`mood_source`의 `ai` 채택률로 측정)
- Gemini 무료 티어 정책이 바뀌거나 모델이 중단될 때

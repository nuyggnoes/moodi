Moodi 화면 설계, 이렇게 접근하세요                                                                                                                       
                                                                                                                                                           
  설계 순서 (4단계)                                                                                                                                        
                                                                                                                                                           
  1. 사용자 시나리오를 언어로 먼저 써라                                                                                                                    
  화면부터 그리지 말고, "퇴근길 지하철에서 지금 감정을 기록하고 싶다" 같은 구체적인 시나리오 3~5개를 문장으로 쓰세요. 그러면 페이지 이동 흐름이 자연스럽게 
  나옵니다.
  2. 각 페이지의 단 하나의 목적을 문장으로 정의해라
  예: /record는 "지금 이 순간의 감정과 음악을 빠르게 포착하는 것". 이게 명확해야 화면에서 뭐가 크고 작아야 하는지가 결정됩니다.
  3. 정보 계층을 손으로 박스만 그려라
  색상, 폰트 없이 "무엇이 위에 있어야 하나, 얼마나 커야 하나"만 스케치.
  4. 그 다음에 인터랙션 설계
  탭/스와이프/버튼 눌렀을 때 무슨 일이 벌어지는지.

  ---
  Moodi에서 특히 중요한 UX 포인트

  - 감정 기록의 마찰을 최소화: /record는 2~3번 탭으로 완료 가능해야 함. 기록은 가벼운 행위여야 합니다.
  - 앨범 아트가 감성의 중심: 단순 썸네일이 아니라 화면 분위기 자체를 결정. 색감을 배경에 번지게 하는 방식 고려.
  - 피드는 공감의 장: 좋아요 숫자보다 기분 태그와 앨범 아트가 먼저 눈에 들어와야 함.
  - 다크 톤 방향 초기 결정: 음악은 밤에 많이 들으므로 다크 감성이 잘 맞을 가능성 높음.
